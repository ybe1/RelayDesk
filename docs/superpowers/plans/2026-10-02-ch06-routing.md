# Ch06 Contextual Routing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for the preserved Native execution method. Steps use checkbox (`- [ ]`) syntax for tracking. One fresh final backend reviewer; frontend uses the user-approved Vibe exception.

**Goal:** 在现有聊天入口交付多轮指代、正式意图分流、可暂停的订单级售后子流程与幂等演示退款申请。

**Architecture:** 父图完成消解与分类；售后子图确定性选单/查单/扩写/召回，回父图过闸后交Agent。AsyncSqliteSaver承载暂停恢复；MySQL保存消息、动作建议及退款申请，所有写操作保留用户确认边界。

**Tech Stack:** 现有FastAPI、SQLAlchemy/MySQL、LangChain @tool、LangGraph/AsyncSqliteSaver、Milvus RRF与bge-reranker-v2-m3；原生HTML/CSS/JS，无新增组件。

**Spec:** `docs/superpowers/specs/2026-10-02-ch06-routing-design.md`，用户2026-10-02已确认书面设计。

## Global Constraints

- 6模型调用、5工具实际执行、12000累计输入/输出token、120秒活动处理时长；等待用户不计时，用量不重置。
- 只用当前会话近期最多6个完整用户轮次；完整明确问题原样保留，不猜订单或商品事实。
- 意图JSON严格只有intent/confidence，8标签；扩写JSON严格只有queries，1至3条；默认大模型，成本模式默认关闭，阈值0.75且最多升级一次。
- 退款/售后先查订单再扩写和政策检索；通用FAQ不选单、不扩写；既有商品/物流/投诉/闲聊出口保留。
- 候选1001/1002/1003为服务端演示目录，订单/物流不建表；保留一致性mock及mock=true。
- 每条dense/BM25各Top50并RRF，公平合并去重最多50候选，一次统一重排Top10，再过现有置信度闸。
- MySQL仅保存用户确认的演示退款申请，5种固定reason；不真实退款、不承诺到账、不自动转人工。
- 不更换上游/数据库/框架，不改代理设置；正常流程预算走不通时先报告证据并询问用户。
- 框架/API实现前Context7核文档及安装版本；每阶段即时更新dev-notes/ch06.md四项记录。
- 后端TDD；纯Prompt/标注数据用评估验证；前端Vibe，不套正式前端TDD/review。
- 沿用用户已选Native与当前工作区直接实施偏好；当前阶段只写计划，不改产品或数据库。

```python
class JSONSequenceModel:
    def __init__(self, values):
        self.values, self.requests = iter(values), []
        self.kwargs, self.schema = {}, None
    def bind(self, **kwargs):
        self.kwargs.update(kwargs)
        return self
    def bind_tools(self, tools, **kwargs):
        self.schema = None
        self.finish_tool = any(getattr(t, '__name__', '') == 'AgentDecision' for t in tools)
        return self
    def with_structured_output(self, schema, **kwargs):
        self.schema = schema
        return self
    async def ainvoke(self, messages, **kwargs):
        self.requests.append((list(messages), dict(kwargs)))
        value = next(self.values)
        raw = AIMessage(content=json.dumps(value, ensure_ascii=False),
            usage_metadata={'input_tokens':100, 'output_tokens':30, 'total_tokens':130})
        if self.schema is not None:
            return {'raw':raw, 'parsed':self.schema.model_validate(value), 'parsing_error':None}
        if getattr(self, 'finish_tool', False) and 'kind' in value:
            raw.content = ''
            raw.tool_calls = [{'name':'AgentDecision', 'args':value, 'id':'finish', 'type':'tool_call'}]
        return raw
    async def astream(self, messages, **kwargs):
        self.requests.append((list(messages), dict(kwargs)))
        yield AIMessageChunk(content='演示回答[1]',
            usage_metadata={'input_tokens':100, 'output_tokens':5, 'total_tokens':105})
```
