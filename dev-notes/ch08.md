## 2026-10-04 · 动态工具权限规则确认

- 用户关键原话：「逐工具授权，权限配置热更新（推荐）」。
- 关键产出：工具发现不等于执行授权；按本地配置中的 Server + 工具名判定是否允许、读写类别和重试规则。新增工具先登记本地权限，可热生效，无需改核心代码或重启客服服务；验收热发现时先准备授权，再仅重启新增工具所在 MCP Server。
- 用户拒绝或纠偏：未采用按查询工具名前缀自动放行；Server 用途描述、annotations 和模型判断均不能赋予权限。
- 翻车与返工：无。仍处于设计讨论，未建表。
